# Kynara1n

Minecraft mod developer. I mostly work on **OptiFine compatibility** across
Fabric, Forge and NeoForge, plus a few small server-side utilities.

## Projects

**OptiFine compatibility**

- **[OptiFabric-Reforged](https://github.com/Kynarain/OptiFabric-Reforged)** — OptiFine on Fabric, with Fabric API loaded alongside.
- **[OptiForge](https://github.com/Kynarain/OptiForge)** — OptiFine on Forge, with Forge Mod Loader loaded alongside.
- **[OptifiNeoforge](https://github.com/Kynarain/OptifiNeoforge)** — OptiFine on NeoForge, with NeoForge's mod loading pipeline kept alongside.
- **[OptiLithium-Reforged](https://github.com/Kynarain/OptiLithium-Reforged)** — Run OptiFine and Lithium in the same Fabric client.

**Server utilities**

- **[TP-Players](https://github.com/Kynarain/TP-Players)** — A lightweight Fabric server mod adding `/tpp <player>`: anyone can teleport to another player, across dimensions too.
- **[CommandWhitelist](https://github.com/Kynarain/CommandWhitelist)** — Fabric server mod that lets admins whitelist restricted commands in-game, so regular players can use them without OP.
- **[legacy_tripwire](https://github.com/Kynarain/legacy_tripwire)** — Restores legacy tripwire behavior: strings disarmed with shears stay disarmed and keep emitting a redstone signal until triggered again.
